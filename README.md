Frequently Asked Questions

How do I play?
Start your development journey and follow the instructions in the game. Complete jobs, deal with customers and try to keep your property empire running.

Is the game offline?
The game is designed to run locally on your device.

I've encountered a problem. What should I do?
If you experience a bug, unexpected behaviour or another issue, please report it here.

When reporting an issue, please include:
- Your device model.
- Your iOS version.
- A description of the problem.
- Steps to reproduce the issue, if possible.

Contact

For questions, feedback or technical support, please use the GitHub Issues section of this repository.
